## Шаг 4: Создать scripts/build-deb.sh

**Файл:** `scripts/build-deb.sh`

### Структура скрипта:

```bash
#!/usr/bin/env bash
set -euo pipefail

# Конфигурация
APP_NAME="git-gui"
APP_VERSION="1.0.0"
MAIN_CLASS="com.gitgui.ui.App"
APP_DIR="$(cd "$(dirname "$0")/.." && pwd)"

# Переход в корень проекта
cd "$APP_DIR"

# Шаг 1: Сборка через Gradle
echo "=== Building with Gradle ==="
./gradlew clean build installDist --no-daemon

# Шаг 2: Найти установленную директорию
APPDIR="build/install/git-gui"
if [ ! -d "$APPDIR" ]; then
    echo "ERROR: $APPDIR not found"
    exit 1
fi

# Шаг 3: Найти все JavaFX jar'ы
JAVAFX_LIBS=$(find "$APPDIR" -name "*javafx*" -o -name "*gluon*" | tr '\n' ':')

# Шаг 4: jpackage
jpackage \
    --type deb \
    --name "$APP_NAME" \
    --app-version "$APP_VERSION" \
    --input "$APPDIR/lib" \
    --main-jar "$(ls "$APPDIR/lib"/*.jar | head -1)" \
    --main-class "$MAIN_CLASS" \
    --java-options "--module-path $APPDIR --add-modules javafx.controls,javafx.fxml,javafx.graphics" \
    --linux-shortcut \
    --linux-menu-group "Development" \
    --dest "build/dist"

echo "=== DONE ==="
ls -la build/dist/*.deb
```

### Ключевые моменты:
- Использует `installDist` вместо кастомных задач
- `$APPDIR` в `--java-options` для JavaFX module path
- Не использует ручной jlink или dpkg-deb инъекции
- Простой и понятный, без лишних шагов
