# План реализации Git GUI

## Обзор

Десктопное Git GUI приложение: Kotlin JVM + JavaFX (pure Kotlin UI, без FXML) + Gradle + JGit (локальные операции) + системный git (сетевые операции) + XDG-конфиг + JUnit 5 тесты.

**Почему pure Kotlin UI вместо FXML:** Единое главное окно + пара диалогов. Pure Kotlin UI проще для динамического поведения (цвета, эмодзи, enable/disable логики) и не требует разделения файлов/виринга контроллеров.

## Шаг 3: Config + ConfigTest

### Файл: `src/main/kotlin/com/gitgui/core/config/Config.kt`

```kotlin
@Serializable
data class AppConfig(
    val recentProjects: List<RecentProject> = emptyList(),
    val lastRepository: String? = null
)

@Serializable
data class RecentProject(
    val path: String,
    val name: String,
    val lastOpened: String  // ISO-8601
)

object Config {
    private val configDir: Path get() {
        val xdg = System.getenv("XDG_CONFIG_HOME")
        return Paths.get(xdg ?: System.getProperty("user.home") + "/.config", "git-gui")
    }
    private val configFile: Path get() = configDir.resolve("config.json")
    private const val MAX_RECENT = 10

    fun load(): AppConfig {
        if (!configFile.exists()) return AppConfig()
        val json = configFile.readText()
        return Json { ignoreUnknownKeys = true }.decodeFromString(json)
    }

    fun save(config: AppConfig) {
        configDir.toFile().mkdirs()
        val json = Json { ignoreUnknownKeys = true }.encodeToString(config)
        val temp = configFile.resolveSibling(configFile.fileName.toString() + ".tmp")
        temp.writeText(json)
        Files.move(temp, configFile, StandardCopyOption.ATOMIC_MOVE, StandardCopyOption.REPLACE_EXISTING)
    }

    fun addRecentProject(config: AppConfig, repoPath: String): AppConfig {
        val name = File(repoPath).name
        val now = Instant.now().toString()
        val updated = config.recentProjects
            .filter { Paths.get(it.path).exists() }  // удалить мёртвые
            .toMutableList()
        updated.removeAll { it.path == repoPath }   // дедуп
        updated.add(0, RecentProject(repoPath, name, now))  // поднять наверх
        while (updated.size > MAX_RECENT) updated.removeAt(updated.lastIndex)  // FIFO
        return config.copy(recentProjects = updated)
    }

    fun clearRecentProjects(config: AppConfig): AppConfig = config.copy(recentProjects = emptyList())
}
```

## Шаг 5: SystemGit + SystemGitTest

### Файл: `src/main/kotlin/com/gitgui/core/git/SystemGit.kt`

```kotlin
class SystemGit(private val repoPath: String) {
    data class ProcessResult(val exitCode: Int, val stderr: String)

    private fun runGit(vararg args: String): ProcessResult {
        val pb = ProcessBuilder("git", *args)
            .directory(File(repoPath))
            .redirectErrorStream(false)  // раздельный вывод для ошибок
        val process = pb.start()
        val stderr = process.errorStream.bufferedReader().use { it.readText() }
        val exitCode = process.waitFor()
        return ProcessResult(exitCode, stderr.trim())
    }

    fun clone(url: String, targetDir: String): ProcessResult
    fun push(remote: String = "origin", branch: String = "HEAD"): ProcessResult
    fun pull(remote: String = "origin", branch: String = "HEAD"): ProcessResult
    fun fetch(remote: String = "origin"): ProcessResult
    fun listRemotes(): List<String>
}
```

**Ключевой момент:** `redirectErrorStream(false)` — stderr нужен для показа ошибок пользователю. SSH-ключи и agent подхватываются из окружения JVM автоматически.

        "--type", "deb",
        "--dest", "${layout.buildDirectory.get().asFile.path}/packages",
        "--vendor", providers.gradleProperty("app.maintainer").get()

## Ключевые технические решения

1. **Pure Kotlin UI** — без FXML, всё в коде. Проще для динамического поведения.
2. **SystemGit stderr** — `redirectErrorStream(false)`, stderr показывается пользователю при ошибках push/pull/clone.
3. **SSH auto-inherit** — ProcessBuilder наследует окружение JVM → SSH_AUTH_SOCK, HOME, GIT_* подхватываются автоматически.
4. **Atomic config writes** — temp file в той же директории + `Files.move(ATOMIC_MOVE)`.
5. **Empty repo handling** — для репозитория без коммитов все файлы индекса считаются staged.
6. **Stage file missing on disk** — если файла нет при stage, удаляем из индекса (`git rm --cached`).
