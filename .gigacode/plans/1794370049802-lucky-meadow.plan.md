# План исправления кодировки локализации

## Проблема

Java ResourceBundle по умолчанию загружает `.properties` файлы в кодировке ISO-8859-1, а не UTF-8. Это приводит к:
1. Русские символы отображаются как `?` (вопросительные знаки)
2. Эмодзи (UTF-16) также повреждаются

**Причина:** `ResourceBundle.getBundle()` использует `PropertiesResourceBundleControl`, который вызывает `Properties.load()` без указания кодировки → по умолчанию ISO-8859-1.

## Решение

Создать кастомный `ResourceBundle.Control` с UTF-8 загрузчиком.

---

## Шаг 1: Создать UTF8Control

**Файл:** `src/main/kotlin/com/gitgui/core/i18n/UTF8Control.kt`

```kotlin
package com.gitgui.core.i18n

import java.io.InputStreamReader
import java.io.BufferedReader
import java.nio.charset.StandardCharsets
import java.util.*

/**
 * Кастомный Control для ResourceBundle с поддержкой UTF-8.
 * Решает проблему с русскими символами и эмодзи.
 */
class UTF8Control : ResourceBundle.Control() {

    override fun loadBundle(
        baseName: String,
        locale: Locale,
        format: String,
        bundle: ResourceBundle,
        reload: Boolean
    ): ResourceBundle? {
        val bundleName = toBundleName(baseName, locale)
        val resourceName = toResourceName(bundleName, format)
        
        val stream = bundle.classLoader.getResourceAsStream(resourceName)
            ?: return super.loadBundle(baseName, locale, format, bundle, reload)
        
        return try {
            val properties = Properties()
            // Читаем файл как UTF-8!
            InputStreamReader(stream, StandardCharsets.UTF_8).use { reader ->
                BufferedReader(reader).use { br ->
                    properties.load(br)
                }
            }
            object : ResourceBundle() {
                override fun handleGetObject(key: String): Any? = properties[key]
                override fun keys(): Enumeration<String> = properties.keys() as Enumeration<String>
            }
        } catch (e: Exception) {
            e.printStackTrace()
            super.loadBundle(baseName, locale, format, bundle, reload)
        }
    }
}
```

## Шаг 2: Обновить LocaleManager

**Файл:** `src/main/kotlin/com/gitgui/core/i18n/LocaleManager.kt`

Изменить инициализацию:
```kotlin
object LocaleManager {
    private var currentLocale: Locale = Locale("ru")
    private val control = UTF8Control()
    private var resourceBundle: ResourceBundle = ResourceBundle.getBundle(
        "messages", 
        currentLocale, 
        LocaleManager::class.java.classLoader,
        control  // ← используем UTF-8 control
    )

    val current: Locale get() = currentLocale

    fun getString(key: String): String = resourceBundle.getString(key)

    fun setLocale(locale: Locale) {
        currentLocale = locale
        resourceBundle = ResourceBundle.getBundle(
            "messages",
            locale,
            LocaleManager::class.java.classLoader,
            control  // ← используем UTF-8 control
        )
    }

    fun isEnglish(): Boolean = currentLocale == Locale.ENGLISH
}
```

## Шаг 3: Проверить файлы ресурсов

Убедиться, что файлы сохранены в UTF-8:
```bash
file src/main/resources/messages.properties
file src/main/resources/messages_en.properties
file src/main/resources/messages_ru.properties
```

Если не UTF-8 — пересохранить:
```bash
# Проверка
file src/main/resources/*.properties

# Если нужно, конвертировать
iconv -f ISO-8859-1 -t UTF-8 src/main/resources/messages.properties > /tmp/msg.properties
mv /tmp/msg.properties src/main/resources/messages.properties
```
