# Git GUI

Десктопное приложение для работы с Git, написанное на Kotlin с использованием JavaFX. Предоставляет визуальный интерфейс для отслеживания изменений, управления индексом, создания коммитов и работы с удалёнными репозиториями.

## Возможности

- **Визуальный просмотр изменений** — отслеживание модифицированных, удалённых и неизвлекаемых файлов
- **Управление индексом** — добавление/удаление файлов из staging area
- **Создание коммитов** — с указанием сообщения и просмотром истории
- **Сетевые операции** — push, pull, fetch через системный git
- **Клонирование репозиториев** — поддержка HTTPS и SSH
- **Недавние проекты** — автоматическое сохранение и быстрый доступ к последним репозиториям
- **Цветовая индикация** — каждый тип файла имеет свой цвет и эмодзи-иконку

## Архитектура

```
Git GUI
├── UI (JavaFX)
│   ├── MainWindow — главное окно с MenuBar и тулбаром
│   ├── widgets — переиспользуемые компоненты (FileListWidget, CommitAreaWidget)
│   └── dialogs — диалоги (CloneDialog, HistoryDialog)
├── Core
│   ├── git — работа с Git
│   │   ├── JGitRepo — локальные операции (JGit)
│   │   ├── SystemGit — сетевые операции (git CLI)
│   │   └── GitRepo — фасад над слоями
│   ├── models — доменные модели
│   │   ├── FileStatus — статус файла
│   │   ├── CommitInfo — информация о коммите
│   │   └── RepoStatus — статус репозитория
│   └── config — управление конфигурацией
└── Resources
    └── icon.png — иконка приложения
```

### Ключевые решения

- **Pure Kotlin UI** — весь интерфейс создаётся программно, без FXML
- **Два слоя Git** — JGit для локальных операций, системный git для сети
- **XDG-конфиг** — настройки хранятся в `~/.config/git-gui/config.json`
- **Атомарные записи** — конфиг сохраняется через temp-файл + atomic move

## Использование

### Главное окно

Приложение состоит из трёх основных зон:

1. **Верхняя панель** — MenuBar (File, Git, Help) и тулбар с кнопками
2. **Центральная область** — три панели:
   - Изменённые файлы (слева)
   - Проиндексированные файлы (стэйдж, центр)
   - Информация о репозитории (справа)
3. **Нижняя панель** — статус-бар с сообщениями

### Меню File

- **Open Repository** (Ctrl+O) — открыть существующий репозиторий
- **Clone Repository** (Ctrl+K) — клонировать новый репозиторий
- **Recent Projects** — список недавних репозиториев
- **Close** (Ctrl+W) — закрыть текущий репозиторий
- **Exit** (Ctrl+Q) — выйти из приложения

### Меню Git

- **Refresh** (Ctrl+R) — обновить статус
- **Stage All** — добавить все изменения в индекс
- **Commit** (Ctrl+S) — создать коммит
- **Push/Pull/Fetch** — сетевые операции (доступны при наличии удалённых репозиториев)

### Цветовая индикация файлов

| Тип файла | Эмодзи | Цвет |
|-----------|--------|------|
| Изменённый | 📄 | Синий (#2196F3) |
| Удалённый | 🗑️ | Красный (#F44336) |
| Неизвлекаемый | 🖳 | Серый (#8B8B8B) |
| Проиндексированный | ✓ | Зелёный (#4CAF50) |
| Переименованный | 📋 | Фиолетовый (#9C27B0) |

## Конфигурация

Конфигурация хранится в JSON-файле:

```json
{
  "recentProjects": [
    {
      "path": "/home/user/projects/my-app",
      "name": "my-app",
      "lastOpened": "2025-09-01T12:00:00Z"
    }
  ],
  "lastRepository": "/home/user/projects/my-app"
}
```

**Путь к конфигу:**
- Linux: `~/.config/git-gui/config.json`
- Можно переопределить через `XDG_CONFIG_HOME`

**Ограничения:**
- Максимум 10 недавних проектов
- Мёртвые пути автоматически удаляются
- Существующие проекты поднимаются наверх (push-to-top)

## Разработка

### Добавление новой функции

1. Реализовать логику в `core/git/` или `core/models/`
2. Добавить UI-компоненты в `ui/widgets/` или `ui/dialogs/`
3. Написать тесты в `src/test/kotlin/`
4. Проверить сборку: `./gradlew clean build`

### Структура виджетов

```
FileListWidget — ListView с фильтрацией по типам файлов
CommitAreaWidget — TextArea для сообщения + кнопки Commit/History
RecentProjectsPane — ListView недавних проектов
```

### Работа с Git

- **Локальные операции** (status, stage, commit, history) → JGit
- **Сетевые операции** (clone, push, pull, fetch) → SystemGit (git CLI)
- Оба слоя работают с одним `.git`, рассинхронизации невозможны
